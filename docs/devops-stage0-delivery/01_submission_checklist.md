# Submission Checklist

Before running the official submission flow:

- [ ] live domain confirmed
- [ ] exact HNG username confirmed
- [ ] valid Let's Encrypt certificate confirmed
- [ ] root page visible username confirmed
- [ ] `/api` exact JSON confirmed
- [ ] HTTP to HTTPS `301` confirmed
- [ ] Nginx active confirmed
- [ ] UFW active confirmed
- [ ] checker SSH key installed or explicitly waived
- [ ] sign-off log complete

Submission fields required by the brief:

- live domain
- HNG username
